## Processed Dataset

The processed dataset is generated after:

- Missing value treatment
- Data type conversion
- Duplicate handling
- Date feature extraction
- Outlier analysis
- Feature engineering

This dataset is used for analytics and machine learning modeling.

## Purpose

The datasets support:

- Power demand analytics
- Exploratory data analysis
- Machine learning
- Explainable AI
- Forecasting
- Conversational analytics

within the AutoInsight AI framework.
